# Domenico Paolo — academic website

Open `index.html` locally to preview. To publish: create a public repository named `nico9902.github.io`, upload `index.html` and `.nojekyll` to the root of `main`, then go to Settings → Pages → Deploy from a branch → main / (root) → Save. The expected URL is https://nico9902.github.io/.

Edit the HTML directly to update biography, publications and projects. The site is static and has no build dependencies. The avatar loads from GitHub. Publication metadata is a selected list, not automatically synchronized with Scholar or Scopus. The original CV is deliberately not published because it contains personal data. Review the page before publishing.
